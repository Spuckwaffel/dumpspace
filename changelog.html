Changelog

New features and changes to the Dumpspace website.

  1. Jan 2025

    Inheritance Viewer

    The Inheritance Viewer shows a graph of every class that inherits from a chosen class, with an adjustable depth.

  2. Aug 2024

    Dumpspace generation 1.02.02

    Adds the array dimension attribute, so C-style arrays show properly on the website. Also brings many UI improvements and several bug fixes.

  3. Jul 2024

    Starboard

    A starboard now showcases the top contributors of the website.

  4. Mar 2024

    Full mobile support

    Mobile support is finished, even for small devices, alongside many UI improvements and small improvements to Global Search.

  5. Feb 2024

    Global Search and API launch

    Global Search and the Dumpspace API are available for all listed games.

  6. Dec 2023

    First public release and announcement

    The project was released to the public for testing and adding games.

  7. Nov 2023

    Final touches before release

    The game viewer was finished and the final UI touches were made.

  8. Sep 2023

    First look

    Dumpspace went public on GitHub for testing.

  9. Aug 2023

    Project start

    Start of the Dumpspace project.
